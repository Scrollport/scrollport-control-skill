# Contributing

Propose control-Skill changes here, in root `SKILL.md`, and bump its date-based
`version`. Run `npm test` before proposing a change. Coordinate product-contract
changes with the [Scrollport product repository](https://github.com/v20x/scrollport).

Outcome Skills belong in their category repositories. Keep this repository to
one control Skill. Roll back guidance with a new version so saved copies notice.

For the initial source-ownership cutover, merge this repository's root document
first and verify its raw URL, then deploy the website redirect. Future guidance
edits require no website deployment.
